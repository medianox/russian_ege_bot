**Салихова Рания, Мастыкина Саша, Палова Таня, Ежов Кирилл — все из 251**

Телеграм-бот для подготовки к ЕГЭ по русскому. С ним можно тренировать задания #4 (Постановка ударения), #5 (Употребление паронимов), #9-12 (Орфография), #13 (Правописание НЕ и НИ) по отдельности или в разнобой. Также он каждый  день присылает напоминание, сколько дней осталось до ЕГЭ, ему можно написать в любой момент ‘сколько?’ — он ответит, сколько дней осталось до ЕГЭ. При решении считает страйки (количество правильных ответов подряд), при вводе или выборе неправильного ответа присылает смешную глупенькую картинку, предлагает пользователю или попытаться еще раз, или показать правильный ответ. 

Гитхаб: есть файл с полным кодом, в папке лежат картинки pic1.png, pic2.png… — их будет высылать бот, там же лежат задания, которые обкачивались из txt (tasks.txt и др.) и pdf; файлы, использованные в критериях к проекту — для ии, ридми и requirements.

Сейчас бот доступен через чат. Если вы захотите организовать бота с локального устройства, то скопируйте репозиторий и запустите файл main.py через консоль (python main.py) с выбором нужной директории.
